# Aravaan — Manuscript Repository

Welcome to the working manuscript repository for **Aravaan**, a 110,000-word trilogy.

## Structure

The trilogy is divided into three major sections:

| Section | Description |
|---|---|
| [Book One](./book-one/README.md) | Present day — Vyaan's return and the unfolding crisis |
| [Codex](./codex/README.md) | Historical context — the past that shapes everything |
| [Book Two](./book-two/README.md) | Return to the present — revelations and resolution |

## How to Navigate

- Each section has its own index listing all cantos in reading order.
- Canto files are named `canto-XX-title.md` within each section folder.
- Where cantos are grouped thematically, the index notes the grouping.
- The [Editorial Notes](./editorial-notes/README.md) folder holds feedback, review threads, and running commentary.

## Editorial Notes

Ongoing review and feedback lives in [`editorial-notes/`](./editorial-notes/README.md). Each round of feedback is logged by canto and topic (narrative structure, character development, prose, themes, overall arc).
