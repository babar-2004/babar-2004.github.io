# The Aravaan Trilogy — Manuscript Repository

This repository holds the working manuscript for the Aravaan trilogy.  
The narrative spans two books in the present timeline, bridged by a Codex that establishes the deep past.

---

```
└── book-two/          — Book Two: return to the present
```
