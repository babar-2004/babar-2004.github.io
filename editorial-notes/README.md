# Editorial Notes

This folder collects all review feedback, commentary, and discussion threads for the manuscript. Notes are organized by canto and by topic.

## Review Topics

Each note may cover one or more of the following dimensions:

- **Narrative Structure** — pacing, scene construction, transitions
- **Character Development** — arcs, consistency, believability
- **Prose Quality** — clarity, rhythm, word choice, dialogue
- **Themes** — how thematic threads develop and pay off
- **Overall Arc** — how individual cantos serve the trilogy's larger shape
